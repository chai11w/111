# ROI 异常广告分析流程

## 输入边界

只接收 `AlertCase` 异常广告对象：

- `alert_type`：`低效广告` 或 `优质广告`
- `trigger_rule`：ROI 阈值触发规则
- `platform`、`owner`、`category`、`campaign_name`、`ad_name`
- `metrics`：`spend`、`revenue`、`orders`、`clicks`、`impressions`、`ctr`、`cpa`、`roi`

不要重新判断 ROI 是否异常。ROI 是否异常已经由确定性阈值完成。

## 分析原则

- 先说事实，再说推断，最后给建议。
- 只基于输入指标分析，不编造素材、落地页、受众、竞价策略等未提供信息。
- 如果证据不足，明确写“当前数据不足以确认”。
- 第一版 MVP 不自动调预算，只给人工确认建议。
- 对低效广告和优质广告都要给出动作建议：低效广告偏止损，优质广告偏放量和复用经验。

## 固定分析步骤

1. 复述触发规则：说明该广告因 `trigger_rule` 进入分析。
2. 摘要关键数据：至少列出 `roi`、`spend`、`revenue`、`orders`、`ctr`、`cpa`。
3. 判断优先级：结合花费规模、订单量和 ROI 偏离程度，给出 `高`、`中`、`低`。
4. 分析可能原因：从流量质量、点击效率、转化效率、花费规模、订单量稳定性中选择最相关的 2 到 3 点。
5. 给出建议动作：输出可人工执行或确认的动作，不直接执行预算调整。
6. 标注需要人工确认的信息：列出继续判断所需的缺失信息。

## 低效广告分析方法

当 `alert_type` 是 `低效广告`：

- 如果 `ctr` 偏低：优先怀疑素材吸引力、受众匹配或平台流量质量不足。
- 如果 `clicks` 不低但 `orders` 少：优先怀疑落地页、商品价格、优惠力度、购买链路或人群购买意图。
- 如果 `cpa` 高：说明单次转化成本偏高，建议检查出价、受众、素材和转化链路。
- 如果 `spend` 高且 `roi` 低：优先级提高，建议尽快人工复核是否降预算或暂停。
- 如果 `orders` 很少：提示样本量不足，建议结合更长时间窗口复核。

建议动作可选：

- 暂停或降低预算，等待人工确认。
- 替换素材或重新测试卖点。
- 收窄受众或排除低质量人群。
- 检查落地页、价格、库存、优惠和支付链路。
- 延长观察窗口，避免小样本误判。

## 优质广告分析方法

当 `alert_type` 是 `优质广告`：

- 如果 `orders` 和 `spend` 都有一定规模：结果相对更可信，可以建议小幅加预算。
- 如果 `orders` 很少但 `roi` 高：可能是小样本波动，不建议直接大幅放量。
- 如果 `ctr` 高且 `cpa` 低：素材吸引和转化效率都较好，建议复用素材和受众方向。
- 如果 `ctr` 一般但 `cpa` 低：点击后转化质量较好，可重点保留人群或商品组合。
- 如果 `spend` 较低：建议先扩大观察或小幅测试预算，不直接判断为稳定爆款。

建议动作可选：

- 小幅提高预算，并继续观察 ROI 是否保持。
- 复制该广告素材、受众或关键词到新测试组。
- 保留当前投放设置，避免一次性大改导致学习期重置。
- 让投手复盘该广告的素材卖点和人群特征。
- 标记为可沉淀案例，供同品类后续投放参考。

## 优先级规则

优先级不是异常判断，只用于排序处理顺序。

- `高`：低效广告且 `spend >= 150`，或 ROI 明显低于阈值；优质广告且 `spend >= 100` 且订单量较高。
- `中`：花费或订单量有一定规模，但仍需要观察。
- `低`：花费低、订单少或样本量不足，建议继续观察。

## 输出格式

每条异常广告输出以下字段：

- 异常广告：`platform / owner / category / campaign_name / ad_name`
- 异常类型：使用 `alert_type`
- 触发规则：使用 `trigger_rule`
- 关键数据：列出核心 `metrics`
- 优先级：`高`、`中` 或 `低`
- 可能原因：2 到 3 条
- 建议动作：2 到 4 条
- 需人工确认：1 到 3 条

## 禁止事项

- 不把 LLM 分析结果当成最终事实。
- 不让 LLM 判断 ROI 是否达标。
- 不输出“已调整预算”“已暂停广告”等执行结果。
- 不引用输入中不存在的平台后台字段。
- 不为了显得完整而编造原因。
