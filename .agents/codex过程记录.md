# codex过程记录

## 用途

本文件记录用户与模型在完成本次笔试题过程中的协作记录。

本文件与项目记忆分工如下：

- 项目记忆只保存当前项目状态和下一步。
- 本文件保存按时间排列的协作过程。

## 记录规则

- 每次发生与笔试题相关的实质协作，都追加一条记录。
- 记录本地时间，时间使用阿拉伯数字格式。
- 记录用户输入和模型输出。
- 不记录隐藏推理、内部思考、密钥、口令或私人凭据。
- 如果早期消息没有精确时间，就标注为约略时间。
- 记录内容使用中文可读表达。
- 文件名、路径、命令、仓库地址和用户指定的专有名称必须保持原样，不翻译。
