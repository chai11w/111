## 架构规则

- 项目记忆只保存当前事实，不保存完整对话流水。
- 稳定协作规则写入 `AGENTS.md`。
- 当前项目状态写入 `.agents/project_memory.md`。
- 按时间顺序的协作过程写入 `.agents/codex过程记录.md`。
- ROI 是否异常必须由确定性阈值逻辑判断，LLM 不负责判断 ROI 是否达标。
- LLM 只分析已经被阈值筛出的异常广告，并结合投手、品类、点击率、花费、订单数、转化成本等字段生成原因和建议。
- 第一版 MVP 不执行预算调整，只输出预警和建议。
- 协作过程记录中的文件名、路径、命令和仓库地址必须保持原样，不翻译。
- 协作过程记录中的时间必须使用阿拉伯数字格式。
- 协作过程记录新增条目必须追加到 `.agents/codex过程记录.md` 文件末尾。
- 日常记录只追加，不重排；只有用户明确要求整理历史时，才检查并修正历史顺序。
- 代码更新记录目标仓库为 `https://github.com/chai11w/111`。
- 每次准备上传前，必须先排除密钥、本地配置、临时文件、大型正式数据和不应公开的材料。
- 在项目复杂度真正上升前，不新增过多上下文文件。
