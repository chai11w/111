# ROI 异常广告预警报告

## 报告说明

- 数据来源：`data\ad_data_sample.csv`
- 初筛方式：确定性 ROI 阈值
- 分析方式：按 `skills/roi-anomaly-analysis/SKILL.md` 的流程生成离线分析建议
- 重要边界：LLM 分析层不判断 ROI 是否达标，只分析已筛出的异常广告

## 汇总

- 异常广告总数：8
- 低效广告：4
- 优质广告：4

## 异常明细

### 1. Facebook / Alice / Beauty / US_Summer_Sale / FB_US_Creative_A

- 异常类型：低效广告
- 触发规则：roi < 1.2
- 关键数据：roi=0.9，spend=120，revenue=108，orders=3，ctr=0.02，cpa=40
- 优先级：中

可能原因：

- 转化成本偏高，当前花费换来的订单效率不足。

建议动作：

- 让投手人工确认是否降低预算、收窄受众或暂停该广告。
- 保留该广告的 ROI 异常记录，进入下一轮人工复核。

需人工确认：

- 素材版本与投放人群
- 落地页和商品价格
- 是否存在库存、支付或优惠异常

### 2. Facebook / Alice / Beauty / CA_New_User / FB_CA_Video_A

- 异常类型：优质广告
- 触发规则：roi > 3.0
- 关键数据：roi=3.8，spend=80，revenue=304，orders=8，ctr=0.04，cpa=10
- 优先级：中

可能原因：

- ROI 表现较好，但样本规模仍需人工复核。
- 点击率较高且转化成本较低，素材吸引和转化效率都较好。

建议动作：

- 先小幅测试预算或延长观察窗口，不建议直接大幅放量。
- 复用该广告的素材卖点、人群方向或关键词方向到新测试组。

需人工确认：

- 该广告是否处于稳定投放阶段
- 素材卖点和人群特征
- 加预算后 ROI 是否保持

### 3. Google / Ben / Electronics / Brand_Search / GG_Brand_Exact

- 素材卖点和人群特征
- 加预算后 ROI 是否保持

- 素材版本与投放人群
- 落地页和商品价格
